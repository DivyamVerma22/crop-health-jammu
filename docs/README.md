# Documentation Index

This folder collects long-form documentation that supports, but is not part of, the runnable code.

`SETUP.md` walks through environment creation, Earth Engine authentication, model download, and Streamlit launch. Start here on any new machine.

`METHODOLOGY.md` describes the scientific pipeline in narrative form: study area and sampling design, satellite inputs, feature engineering, dataset construction, model benchmarking, validation and SHAP interpretability, multi-step forecasting, deployment, and limitations.

For the README and citation metadata, see the repository root.
